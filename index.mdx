Broccoli Queue is a high-performance, async-first message queue library for Rust applications — inspired by Python's Celery but built for Rust's type system and Tokio async runtime. With a single, ergonomic API you can publish and consume jobs across Redis, RabbitMQ, or SurrealDB without changing your application code.

## Why Broccoli Queue?

If you've used Celery in Python and want the same flexibility in Rust, Broccoli Queue is the answer. It gives you a consistent, broker-agnostic API while leveraging Rust's ownership model and async/await for safe, high-throughput job processing.

## Get Started in Three Steps

<Steps>
  <Step title="Add the dependency">
    Add `broccoli_queue` to your `Cargo.toml` with the broker feature you need:

    ```toml Cargo.toml
    [dependencies]
    broccoli_queue = { version = "0.4", features = ["redis"] }
    tokio = { version = "1", features = ["full"] }
    serde = { version = "1", features = ["derive"] }
    ```
  </Step>
  <Step title="Publish a message">
    Build a queue and publish a typed message:

    ```rust publisher.rs
    use broccoli_queue::queue::BroccoliQueue;
    use serde::{Serialize, Deserialize};

    #[derive(Clone, Serialize, Deserialize)]
    struct Job { id: String, task: String }

    #[tokio::main]
    async fn main() -> Result<(), Box<dyn std::error::Error>> {
        let queue = BroccoliQueue::builder("redis://localhost:6379")
            .pool_connections(5)
            .build()
            .await?;

        queue.publish("jobs", None, &Job {
            id: "1".into(),
            task: "send_email".into(),
        }, None).await?;
        Ok(())
    }
    ```
  </Step>
  <Step title="Consume and process">
    Start a worker that processes messages with automatic ack/reject handling:

    ```rust consumer.rs
    use broccoli_queue::{queue::BroccoliQueue, brokers::broker::BrokerMessage};
    use serde::{Serialize, Deserialize};

    #[derive(Clone, Serialize, Deserialize)]
    struct Job { id: String, task: String }

    #[tokio::main]
    async fn main() -> Result<(), Box<dyn std::error::Error>> {
        let queue = BroccoliQueue::builder("redis://localhost:6379")
            .pool_connections(5)
            .failed_message_retry_strategy(Default::default())
            .build()
            .await?;

        queue.process_messages("jobs", Some(4), None,
            |msg: BrokerMessage<Job>| async move {
                println!("Processing: {}", msg.payload.task);
                Ok(())
            }
        ).await?;
        Ok(())
    }
    ```
  </Step>
</Steps>
